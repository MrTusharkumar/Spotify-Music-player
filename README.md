
## 🎵 Spotify Music Player Clone
  A responsive and interactive Spotify-inspired music player built with modern web technologies. This project replicates core Spotify functionalities such as play, pause, next/previous track, and playlist management, offering a smooth and intuitive user experience.

  ## 🔧 Features
  ▶️ Play and pause music

⏭️ Skip to next and previous songs

🎶 Playlist functionality (add, select, switch)

📱 Responsive design for mobile and desktop

⚡ Clean and optimized code for performance

## 💻 Tech Stack
HTML5 & CSS3

JavaScript (Vanilla or React – mention if applicable)

Audio API

## 📁 Project Structure
Organized for easy readability and scalability, with separate components for player controls, playlist rendering, and UI.
